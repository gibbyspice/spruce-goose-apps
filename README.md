# App information site

Public pages for our apps: privacy policy, terms of use and support. Served by GitHub Pages from the `main` branch.

Each app has its own folder (`next-play-baseball/`, `chessrealm-elo-trainer/`) with `index.html`, `privacy.html` and `terms.html`. To add an app, copy that folder, rewrite the three pages from what the app really does, and add a link in the root `index.html`.

When an app changes what data it handles, update its privacy page and the effective date in the same change.
